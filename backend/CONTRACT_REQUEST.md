# Contract requests

Белсенді блоктаушы өзгеріс жоқ. Backend `shared/api.md` және `shared/types.ts`
келісімін өзгертпей қолданады.

T7 (әр шығарылған кандидаттың себебін жеке өріспен беру) кейінге қалдырылды.
Қазір себептер қолданыстағы `MatchResult.message` арқылы беріледі.
FRONT бұл мүмкіндік қажет екенін растаса, екі адам алдымен shared типтері мен
API құжатын келісіп өзгертеді. Бұл сессия жаңа response өрісін қоспады.

FRONT ескеретін шектеу: датасет күнтізбесі 2026-09-23–2026-12-31 аралығында.
Бұл аралықтан тыс күн VALIDATION / HTTP 400 береді. Мердігердің бос екені тек
берілген күнтізбеден анықталады; бронь кепілдігі емес.
