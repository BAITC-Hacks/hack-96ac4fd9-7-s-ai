# Firebird — мердігерлерді ақылды іріктеу

**Негізгі тапсыру нұсқасы — осы түбірдегі Firebird.** Іске қосу: `python server.py --port 8000`. Бұрынғы React/Node.js коды `frontend/` және `backend/` ішінде сақталған; оның бастапқы нұсқаулығы [LEGACY-README.md](docs/LEGACY-README.md) файлында. Ескі `scripts/start.ps1` жолы сол бөлек нұсқаға арналған.

Firebird іс-шара ұйымдастырушысына берілген каталогтан **ең көбі 3 мердігер таңдауға** көмектеседі. Әр карточкада мердігердің неге сәйкес келетіні, бастапқы бағасы және түсіндірмені тексеруге арналған каталог деректері көрсетіледі.

Басты беттен іс-шара идеяларын таңдап, бір мердігерді іріктеуге немесе ортақ бюджетке төрт қызметке дейін команда жинауға болады. Толық каталог, жеке профильдер, күнтізбе, таңдаулылар, салыстыру және іздеу тарихы бір жұмыс жолына біріктірілген.

Жоба HackAlem AI хакатонының **«Мердігерлерді ақылды іріктеу / #79-lite»** кейсіне арналған. Бастапқы каталогта 66 анонимдендірілген профиль бар; есімдер ойдан шығарылған.

## Жылдам іске қосу

**Python 3.10 немесе жаңа нұсқасы** қажет. Python-ның стандартты кітапханасы қолданылады; қосымша пакет немесе модель жүктеу қажет емес. Қолмен толтырылатын іріктеу API кілтінсіз жұмыс істейді. Еркін мәтінді түсінетін OpenAI агенті төменде бөлек қосылады.

Репозиторий папкасында:

```powershell
python server.py --port 8000
```

Браузерде **http://127.0.0.1:8000** мекенжайын ашыңыз. Серверді тоқтату: `Ctrl+C`. Windows-та `start.bat` файлын да пайдалануға болады.

**RU:** установите Python 3.10+, запустите указанную команду из папки проекта и откройте адрес в браузере. Дополнительные пакеты не нужны. Ручной подбор работает без ключа; для необязательного OpenAI-агента нужен серверный API-ключ.

**EN:** install Python 3.10+, run the command from the repository folder and open the local URL. No extra packages are required. Manual matching works without a key; the optional OpenAI agent requires a server-side API key.

## OpenAI агентін қосу

Репозиторий түбіндегі жергілікті `.env` файлына кілтті енгізіңіз немесе `OPENAI_API_KEY` орта айнымалысын беріңіз. Сервер `.env` файлын іске қосылғанда оқиды; өзгерткеннен кейін серверді қайта іске қосыңыз.

```dotenv
OPENAI_API_KEY=YOUR_OPENAI_API_KEY
OPENAI_MODEL=gpt-4.1-mini-2025-04-14
```

`OPENAI_MODEL` міндетті емес; әдепкі мәні — `gpt-4.1-mini-2025-04-14`. Кілт серверде сақталады және браузерге берілмейді; `.env` Git-ке қосылмайды. Осы модельдің Responses API және function calling қолдауы [OpenAI-дың ресми модель құжатында](https://developers.openai.com/api/docs/models/gpt-4.1-mini) көрсетілген.

Агенттің жұмыс реті:

1. OpenAI еркін мәтінді құрылымды сұранысқа айналдырып, міндетті `search_contractors` құралын шақырады.
2. Сервер аргументтерді тексеріп, **сол `recommend()` функциясын** орындайды. Күн, қала, санат, формат, бюджет, тіл және ұзақтық сүзгілері, тұрақты рет және үш карточка шегі Python кодында орындалады.
3. Іріктеу нәтижесі модельге `function_call_output` арқылы қайтарылады. Модель әр карточка үшін сервер берген дәлелдер тізімінен индекс таңдайды. Сервер ID мен индексті тексеріп, бастапқы дерекке сүйенген түсіндірме құрады. Модель жаңа мердігер немесе өз ойынан факт қоса алмайды.

Бұл — [ресми function calling ағынына](https://developers.openai.com/api/docs/guides/function-calling) негізделген екі сатылы агент. OpenAI режимінде сұраныс мәтіні мен іріктелген анонимдендірілген каталог дәлелдері API-ға жіберіледі.

Кілт жоқ болса немесе бірінші саты орындалмаса, **формадағы шарттар бойынша ережелік нәтиже** қайтарылады. Бірінші саты сәтті түсіндіріп, екінші саты істемесе, **түсіндірілген сұраныс сақталып**, оның ережелік нәтижесі беріледі. Жауаптағы `agent.mode` (`ai` немесе `fallback`), `input_source`, `trace`, `request_ids` және қажет болса `fallback_reason` нақты орындалған жолды көрсетеді. `GET /api/agent/status` кілттің конфигурацияланғанын көрсетеді; бұл OpenAI-ға сәтті сұраныс жасалғанын білдірмейді.

## Негізгі сценарий

1. Қаланы, күнді, іс-шара форматын, мердігер санатын және бюджетті енгізіңіз.
2. Қажет болса, тілді, ұзақтықты және сипаттамаға қатысты қалауды қосыңыз.
3. Іріктеу нәтижесін ашып, 1–3 карточканың түсіндірмесін салыстырыңыз.
4. Карточкадағы дереккөзді ашып, түсіндірменің бастапқы сипаттамаға сәйкестігін тексеріңіз.
5. Күнді не бюджетті өзгертіп, нәтиженің қалай өзгеретінін көріңіз.
6. Профильді ашып, сақтаңыз немесе салыстыруға қосыңыз. Бұрынғы сұранысқа тарихтан оралыңыз.

| Бет | Не істейді |
|---|---|
| `/` | Іс-шара түрлері, идея үлгілері, санаттар және жоспарлау құралдары |
| `/match` | Шарттар бойынша үшке дейін дәлелді ұсыныс — хакатонның негізгі сценарийі |
| `/planner` | Ортақ бюджетке 1–4 қызметтен команда, жақын күндер, дайындық тізімі және жоспар экспорты |
| `/catalog` | Қала мен санат бойынша сүзу; атау, ID немесе сипаттама бойынша іздеу; баға/атау бойынша сұрыптау және беттеу |
| `/contractor/ID` | Толық сипаттама, форматтар, тілдер, бастапқы баға, дерек белгілері және күнтізбе |
| `/saved` | Осы браузерде сақталған таңдаулылар |
| `/compare` | Үшке дейін профильді бір кестеде, таңдалған күннің қолжетімділігімен салыстыру |
| `/history` | Соңғы он түрлі сұранысты қайта ашу |

Каталог беті толық тізімді баға немесе атау бойынша реттейді. Ұсыныстар беті іс-шараның барлық шартын тексеріп, сипаттама сәйкестігі бойынша үшке дейін мердігер таңдайды. Салыстыру бетінде күн көрсетіледі; API-ға күнсіз сұраныс берілсе, бос/бос емес мәртебесі белгісіз деп қайтарылады.

Таңдаулылар, салыстыру тізімі және соңғы он түрлі сұраныс `localStorage` арқылы **осы браузерде және осы сайт мекенжайында** сақталады. Тіркелгі немесе құрылғылар арасында синхрондау жоқ. Браузер деректерін тазалау оларды жояды; тұрақты сақтау қолжетімсіз болса, ағымдағы беттегі уақытша жад пайдаланылады.

Үш жағдай бөлек көрсетіледі:

- **Сәйкестер бар:** табылғандардың ішінен ең көбі үш карточка беріледі.
- **Қалада бұл санат жоқ:** каталогта қала мен санаттың өзі кездеспейді.
- **Мердігерлер бар, шартқа сай келмейді:** бос емес күн, формат, бюджет, тіл немесе ұзақтық себебі түсіндіріледі.

Шарттарға тек бір не екі мердігер сәйкес келсе, сервис соларды ғана көрсетеді. Бюджетті немесе күнді өзгерту ұсынысы берілсе, ол каталог бойынша қайта тексерілген өзгеріс болады.

## Іс-шараны бірге жоспарлау

**«Менің іс-шарам»** бөлімінде клиент жалпы бюджетін және төртке дейін қызмет санатын таңдайды. Мысалы: жүргізуші, фотограф, банкет залы және жанды музыка тобы. Сервис әр санатқа бір мердігерден құралған үшке дейін команда нұсқасын қайтарады.

- Команда мүшелері бір қала, күн, формат, тіл және ұзақтық шарттарынан өтеді. Бастапқы бағалар қосындысы жалпы бюджеттен аспайды.
- Бірнеше санатта кездесетін бір профиль екі қызметке бірдей қойылмайды: әр командадағы ID қайталанбайды.
- Толық команда табылмаса, жетіспейтін санаттар мен себептер көрсетіледі. Қолжетімді болса, толық командаға керек ең аз бастапқы бюджет есептеледі.
- **Жақын күндер** келесі 14 күнді каталог терезесінің ішінде тексереді: қанша санат жабылады, толық команда мүмкін бе, ең аз жалпы бастапқы баға бюджетке сыя ма.
- Клиент дайындық тізімін жүргізе алады, жобасын осы браузерде сақтайды және жоспарды файлға шығарады.

Бұл — каталогтағы **«бастап» бағаларының қосындысы**. Сметаға расталмаған тамақ, жол, жабдық, қосымша уақыт немесе басқа шығындар ойдан қосылмайды. Қолжетімділік брондау ретінде көрсетілмейді. Идея карточкаларындағы бюджеттер — өзгертуге болатын сұраныс мысалдары.

Ұқсас сервистерден алынған өнім үлгілері және өз шешіміміздің айырмашылығы [зерттеу құжатында](docs/RESEARCH.md) берілген.

## Іріктеу және түсіндірме

Алдымен қала мен санат алынады. Одан кейін бос емес күн, формат, бюджет, тіл және ұзақтық шарттары тексеріледі. Сол күнге `busy_dates` тізімінде тұрған мердігер, соның ішінде зал немесе қонақүй, нәтижеге кірмейді.

Қалған кандидаттар сипаттаманың іс-шара форматына және пайдаланушы қалауына сәйкестігі бойынша тұрақты ережемен реттеледі. Тең ұпай кезінде төмен бастапқы баға, одан кейін `id` қолданылады. Бірдей каталог пен сұраныс карточкалардың бірдей ретін береді.

Ұпай есебі: форматқа қатысты әр ұғым тобы — **+3**, қалауға сәйкес топ — **+6**, басқа сөз сәйкестігі — **+2**; қажет емес деп көрсетілген топ — **−6**. Бұл ереже бастапқы сүзгілерден өткен кандидаттарға ғана қолданылады.

Түсіндірме каталогтағы нақты деректерден құралады: мердігердің ерекшелігі, сұраныс күні, бастапқы баға және бюджетпен сәйкестік. Бастапқы орысша сипаттама карточкадағы дәлел ретінде өзгеріссіз беріледі. Қазақша және орысша интерфейс қолданылады.

Ерекше тілекке нақты сәйкес дерек табылса, түсіндірмеге бастапқы сипаттамадан дәл үзінді қосылады. Мысалы, «импровизация» тілегінің дәлелі сол сөз кездесетін түпнұсқа үзіндімен бірге көрсетіледі. Сәйкестік расталмаса, тілек орындалды деп мәлімделмейді.

**Құрылымды өрістер сүзуге негіз болады.** Егер сипаттама мен `languages`, `city` немесе басқа құрылымды өріс қайшы келсе, еркін мәтін сүзу шартын өзгертпейді. Мысалы, `HK-77838` сипаттамасында қазақ тілі аталғанымен, `languages` өрісінде орыс және қазақ тілдері бар; тіл сүзгісі осы өрісті қолданады.

Бас тарту саны қайталанбай есептеледі: әр кандидатқа бірінші өтпеген шарт тағайындалады. Реті: **күн → формат → бюджет → тіл → ұзақтық**. Сондықтан осы сандар мен сәйкес кандидаттар саны қала/санат бойынша бастапқы кандидаттар санын береді.

## Архитектура және технологиялар

```text
Браузер: HTML + CSS + JavaScript
                  │ JSON / HTTP
                  ▼
         server.py — жергілікті HTTP сервер
                  │
                  ▼
         matcher.py — сүзу, реттеу, түсіндірме
         catalog_service.py — каталог, профиль, салыстыру
         planner.py — ортақ бюджетке командалар және жақын күндер
                  │
                  ▼
         data/catalog.csv — берілген 66 профиль
```

| Файл немесе папка | Қызметі |
|---|---|
| `server.py` | Статикалық беттер және JSON API |
| `matcher.py` | CSV оқу, валидация, іріктеу, түсіндірме және өзгеріс ұсыныстары |
| `ai_agent.py` | OpenAI құрал шақыру циклі, дәлел индексін тексеру және ережелік fallback |
| `ai_transport.py` | Серверлік `.env` конфигурациясы және Responses API-ға HTTPS сұраныс |
| `catalog_service.py` | Каталогты іздеу/беттеу, толық профиль және күнтізбесі бар салыстыру |
| `planner.py` | Әр санатқа жеке ID таңдау, жалпы бюджетті сақтау, ең аз құн мен күн баламаларын есептеу |
| `evidence.py` | Берілген 66 профильдің сипаттамасынан дайындалған қазақша және орысша нақты ерекшеліктер |
| `static/` | Іріктеу және өнім беттерінің интерфейсі; `shared.js` ішіндегі ортақ `FirebirdStore` |
| `data/catalog.csv` | Ұйымдастырушылар берген анонимдендірілген каталог |
| `tests/` | Іріктеу шарттары мен HTTP интеграциясын тексеру |
| [docs/DEMO.md](docs/DEMO.md) | Екі минуттық көрсету сценарийі |
| [docs/SUBMISSION.md](docs/SUBMISSION.md) | Платформаға тапсыру қадамдары және дайын сипаттама |

**AI қолданылуы:** әзірлеуде Codex қолданылды. Өнімдегі қосымша OpenAI агенті еркін мәтінді сұранысқа айналдырып, құрал нәтижесінен дәлел таңдайды. Қолмен іріктеу және fallback каталогқа сүйенетін тұрақты ережелер арқылы жұмыс істейді.

JSON API: `GET /api/meta` — каталог параметрлері мен дайын демолар; `POST /api/recommend` — іріктеу; `GET /api/health` — сервер күйі. Іріктеу сұранысына `previous_query` берілсе, тек күн өзгерген жағдайда жауапта күнтізбемен расталған өзгерістер де беріледі.

Қосымша API:

- `POST /api/agent` — `{message, query, ui_language}`: еркін мәтін, fallback үшін жарамды форма және интерфейс тілі. Жауап — қалыпты іріктеу нәтижесі және `agent` орындалу ақпараты.
- `GET /api/agent/status` — `{configured, model}`; кілттің өзін қайтармайды және модельге сұраныс жасамайды.
- `GET /api/catalog?city=Алматы&category=Ведущий&page=1&page_size=12` — каталог. Іздеу: `q`; сұрыптау: `price_asc`, `price_desc`, `name`; бет өлшемі ең көбі 24.
- `GET /api/contractors/HK-39372` — толық профиль. Белгісіз ID үшін HTTP 404 беріледі.
- `GET /api/compare?ids=HK-88430,HK-77838&date=2026-10-09` — таңдалған ретпен салыстыру. Ең көбі үш түрлі ID; қайталанатын ID немесе жарамсыз күн үшін HTTP 400 беріледі.
- `POST /api/plan` — `{city,date,event_format,categories:["Ведущий","Фотограф"],budget_kzt,language,duration_hours,preferences,ui_language}`. `budget_kzt` — бүкіл команданың бюджеті. Жауапта `bundles`, `summary.category_results`, `summary.minimum_feasible_total_kzt` және `date_radar` бар. Санаттар саны 1–4, қайталанбайды.

Тексерулерді іске қосу:

```powershell
python -m unittest discover -s tests -v
```

Соңғы толық тексеру: **57 Python тесті өтті, 2,578 секунд**. Тексерулер бос емес мердігер мен залды шығармауды, үш карточка шегін, қайталанатын ретті, баға/ұзақтық шекараларын, күн валидациясын, `max_hours=null` мағынасын, үш нәтиже түрін, бастапқы дәлелді және HTTP API жұмысын қамтиды. Каталог іздеуі мен беттеу, профиль белгілері, үштік салыстырудың реті/шегі, күнтізбе және тілекке сәйкес түпнұсқа үзінді де тексеріледі.

OpenAI агентінің құрал циклі мен HTTP маршруты сыртқы желіге шықпайтын енгізілетін транспорт арқылы тексеріледі:

```powershell
python -X utf8 -m unittest discover -s tests -p "test_ai*.py" -v
```

Бұл тесттер қате ID/дәлелді қабылдамауды, бастапқы қатты сүзгілер мен ретті сақтауды, кілтсіз жұмысты және екі сатыдағы ақауларды қамтиды. Жалған транспортпен өткен тест нақты OpenAI сұранысының сәтті өткеніне дәлел болмайды; нақты провайдермен тексеру бөлек жүргізіледі.

Қосымша **16 DOM интеграция сценарийі өтті**: бұрынғы іріктеу, каталог, профиль, сақтау, салыстыру және тарих жолдарына қоса жаңа басты бет, идеядан жоспарға өту, төрт қызметтік команда, күн/бюджет баламалары, ескірген нәтижені экспорттаудан қорғау, checklist, жобаны қайта ашу, TXT/JSON экспорты мен баспа құжатын құрастыру тексерілді. Оның ішінде AI интерфейсінің **3 сценарийі жасанды API жауаптарымен** тексерілді. `jsdom` JavaScript пен DOM әрекеттерін тексереді; нақты браузердің орналасуы, CSS көрінісі және физикалық басып шығару бұл тексеруге кірмейді. Визуалды тексеру аяқталмады: компьютерді басқару құралы браузер URL-ын сенімді анықтай алмай тоқтады.

**Нақты API тексеруінің күйі:** жергілікті HTTP арқылы агент маршруты тексеріліп, кілт берілмегендіктен `fallback` / `not_configured` қайтарды. OpenAI-ға нақты сұраныс әлі жасалмады; серверлік кілт конфигурацияланған соң бұл тексеру бөлек орындалады.

Бұл қосымша тексеруге Node.js 24+ керек. Қосымшаны іске қосу үшін Node.js қажет емес. Серверді бөлек терминалда іске қосып, тексеріңіз:

```powershell
npm install --prefix .local/dom-check --no-audit --no-fund jsdom@30.1.1
node tests/ui_smoke.cjs
node tests/product_smoke.cjs
node tests/agent_smoke.cjs
```

Орнатылған тексеру пакеттері `.local` ішінде қалады және репозиторийге кірмейді.

## Шектеулер

- Күнтізбе тек **23.09.2026–31.12.2026** аралығын қамтиды. Осы аралықтан тыс күн сұранысы қабылданбайды.
- `price_from_kzt` — **бір іс-шараға «бастап» бағасы**. Ол сағаттық тариф те, соңғы расталған ұсыныс та емес.
- `max_hours=null` — жұмыс алаңда қатысу ұзақтығына байланыспайды; бұл мерзімі белгісіз брондау дегенді білдірмейді.
- Бос күн — берілген каталогтағы күнтізбе бойынша. Сервис шынайы уақыттағы қолжетімділікті тексермейді.
- Қала, баға және сипаттамалардағы бастапқы деректердің сапасы нәтижеге әсер етеді. Сипаттамадағы тәжірибе туралы тұжырымдар тәуелсіз расталмаған.
- Қолмен іріктеуде қалаулар сөздер мен ұғымдарды ережемен сәйкестендіру арқылы ескеріледі. Қосылған OpenAI агенті еркін мәтінді түсіндіреді; оның қабылданған шарттары жауаптағы `query` өрісінде көрінеді.
- Каталогта тек берілген деректер көрсетіледі. Клиенттік рейтингтер, пікірлер, расталмаған фотосуреттер және байланыс деректері қосылмаған.
- Таңдаулылар мен тарих браузерде сақталады; серверде пайдаланушы тіркелгісі, бұлттық сақтау немесе синхрондау жоқ.
- Тек ұсыныс беріледі. Брондау, төлем, мердігерге өтінім немесе хабарлама жіберу іске асырылмаған.
- Қазіргі тексеру жолы — жергілікті іске қосу. Орналастырылған нұсқаға сілтеме әлі берілмеген.
