# Мердігерлерді ақылды іріктеу (HackAlem AI, #79-lite)

> **EN summary.** A web service for an event-contractor marketplace in Kazakhstan. The client enters
> city, date, event type, contractor category and budget; the service returns up to three contractors,
> each with a short explanation grounded in profile facts (free date, price vs budget, language,
> duration, a quote from the description). Busy contractors never appear, the order is deterministic,
> and "no such category" vs "candidates exist but none fit" are shown as different outcomes.
> UI and explanations are available in Kazakh, Russian and English. Runs fully offline — no API keys needed.

## Мәселе және шешім

Тапсырыс берушінің алдында қала бойынша мердігерлер каталогы тұр, бірақ «кім маған сәйкес, неге?»
деген сұраққа жауап жоқ. Сервис тізімді ұзартпайды: шарттарға сай 3-ке дейін мердігерді таңдап,
әрқайсысына профильдегі нақты фактілерден құралған 1–2 сөйлемдік түсіндірме береді. Сәйкес
мердігер аз немесе мүлде жоқ болса, себебін сөзбен айтады.

## Архитектура

```
frontend (React + Vite)                       backend (Express + TypeScript)
┌──────────────────────┐   POST /api/match    ┌──────────────────────────────────────────────┐
│ форма → қорытынды →  │ ───────────────────▶ │ 1. қатаң сүзгі (кодпен): қала, санат, формат, │
│ 0–3 карточка немесе  │                      │    бос күн, баға ≤ бюджет, тіл, ұзақтық       │
│ себебі бар хабар     │ ◀─────────────────── │ 2. тұрақты рет: сипаттаманың форматқа         │
│ ҚАЗ / РУС / ENG      │     MatchResult      │    сәйкестігі, тең болса ID бойынша          │
└──────────────────────┘                      │ 3. түсіндірме: профиль үзіндісі + фактілер    │
                                              │ 4. статус: found / no_category / no_match     │
                                              └──────────────────────────────────────────────┘
                                                  ▲ 66 профиль, backend/data/contractors.csv
```

- **Бюджет — жоғарғы шек, сапа белгісі емес.** Баға рейтингке мүлде кірмейді.
- **Детерминизм.** Кездейсоқтық жоқ: бірдей сұраныс әрқашан бірдей карточкаларды бірдей ретпен береді.
  Интерфейс тілі (`locale`) тек мәтінді өзгертеді, құрам мен ретке әсер етпейді.
- **Түсіндірмелер ойдан шығарылмайды.** Олар профильдегі сөйлемнен (түпнұсқа, орысша) және
  тексерілген фактілерден құралады: бос күн, бағаның бюджетке қатысы, жұмыс тілі, ұзақтық.
  «Керемет таңдау» сияқты жалпы сөздер, жұлдызша немесе пайыздық рейтинг жоқ.
- **Бос нәтиже де жауап.** `no_category` — бұл қалада санат жоқ; `no_match` — мердігерлер бар,
  бірақ сай емес, әр себеп (бос емес, бюджеттен қымбат, форматты алмайды...) санымен беріледі.
- Кодта қосымша AI-таңдау модулі бар (`backend/src/ai/`, OpenAI → NVIDIA). Ол тек дайын үзінділер
  мен фактілердің нөмірін таңдайды. Кілт берілмесе, өшірулі тұрады: демо және тексерулер
  кілтсіз, толықтай фактілік шаблондармен жұмыс істейді.

## Іске қосу

Керек: **Node.js 20+** (тексерілген: Node 24). Кілттер мен `.env` міндетті емес.

**1. Backend** (http://localhost:8787):

```powershell
cd backend
npm ci
npm start
```

**2. Frontend** (http://localhost:5173), жаңа терминалда:

```powershell
cd frontend
npm ci
$env:VITE_USE_MOCKS = 'false'
npm run dev
```

`VITE_USE_MOCKS` берілмесе, dev-сервер backend-сіз, синтетикалық моктармен ашылады
(беттің жоғарғы жағында «Демо: синтетикалық деректер» белгісі тұрады).

## Тексеру

## Шектеулер

- Датасетте 66 профиль. Оның 13-і синтетикалық, кейбірінің қаласы немесе бағасы толықтырылған;
  бұл карточкада `dataFlags` белгісімен көрсетіледі. Өз профильдерімізді қоспадық.
- Рет сипаттамадағы сөз топтарына негізделген эвристика: ол сапа рейтингі емес және терістеуді
  толық түсінбейді. Сипаттама — профиль иесінің мәлімдемесі, тәуелсіз расталған факт емес.
- Профильден алынған үзінді түпнұсқа тілінде (орысша) қалады, айналасындағы мәтін аударылады.
- **Есімдер мен аватарлар ойдан шығарылған.** Датасеттегі есімдер де ойдан шығарылған (аниме кейіпкерлері); олар
  id бойынша тұрақты, бірегей қазақ есімдеріне ауыстырылады, сипаттамадағы есім де сол есіммен ауыстырылады
  (`backend/src/lib/displayNames.ts`). Залдар мен топтар — «Ақ Сарай», «Сазген» сияқты атаулар. Жыныс сипаттамада
  айтылса («провела», «он»), сол алынады, әйтпесе id бойынша таңдалады — ол тек аватар мен есім үшін.
  Аватарлар жергілікті түрде жасалатын суретті портреттер (DiceBear «Avataaars», дизайн: Pablo Stanley, жеке және
  коммерциялық қолдануға тегін), нақты адамдардың фотосы емес.
- Брондау, өтінім жіберу және мердігермен байланыс жоқ: сервис тек ұсыныс береді.
