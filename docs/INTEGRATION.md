# Негізгі нұсқаны біріктіру

23.09.2026 күні пайдаланушы қазіргі **Firebird** нұсқасын тапсыруға негізгі нұсқа ретінде таңдады және бұрынғы кодты сақтауды сұрады.

- Firebird: түбірдегі `server.py`, `matcher.py`, `planner.py`, `catalog_service.py`, `evidence.py`, `static/`, `data/`, `tests/`.
- Негізгі іске қосу: `python server.py --port 8000` немесе Windows-та `start.bat`.
- Бұрынғы React/Node.js нұсқасы: `frontend/`, `backend/`, `shared/`, `scripts/`; бұл папкалардың коды өзгертілмейді.
- Бұрынғы түбірлік README өзгеріссіз `docs/LEGACY-README.md` файлына сақталды.
- Екі нұсқаның API келісімдері бөлек. Firebird интерфейсі түбірдегі Python серверімен бірге іске қосылады; оны ескі Express endpoint-терімен араластырмаңыз.

Нұсқа таңдау тарихы үшін ескі ұйымдастыру құжаттары мен branch тарихы сақталады. Түбірдегі осы README — негізгі Firebird-ті іске қосу және тексеру нұсқаулығы.
