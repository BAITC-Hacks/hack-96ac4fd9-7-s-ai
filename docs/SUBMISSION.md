# Firebird шешімін тапсыру

Жоба атауы: **Firebird**

Қысқа идея: **«Бір іс-шара. Ортақ күн. Ортақ бюджет. Әр таңдауға дәлел.»**

## Платформаға қоюға болатын сипаттама

Firebird — іс-шараға берілген каталогтан үшке дейін мердігер таңдайтын сервис. Қосымша OpenAI агенті еркін мәтінді түсіндіріп, каталог іздеу құралын шақырады және тексерілген дәлелдерден түсіндірме таңдайды. Күн, бюджет, формат, тіл және ұзақтық сүзгілері мен тұрақты рет Python кодында сақталады. Кілт жоқ немесе API істемесе, қолданылған шарттары анық көрсетілген ережелік нәтиже беріледі. Өнімде каталог, толық профиль, күнтізбе, таңдаулылар, салыстыру, сұраныс тарихы, команда жоспары және күн радары бар. Сирек санат пен бос нәтиже себеппен түсіндіріледі. Қазақша және орысша интерфейс қолданылады. Негізгі іріктеу кілтсіз іске қосылады; OpenAI режиміне серверлік API кілті қажет. README-де архитектура, конфигурация және қайталанатын тексеру сценарийлері берілген.

## Тапсыру қадамдары

### Кеңейтілген өнім мүмкіндіктері

Басты бетте алты іс-шара түрі, идея үлгілері және нақты каталог санаттары бар. «Менің іс-шарам» бөлімі ортақ күн мен жалпы бюджетке төрт қызметке дейін толық команда жинайды: сәйкестік бойынша, үнемді және балама құрамдар. Бір профиль екі қызметке қайталанбайды. Жақын 14 күннің қолжетімділігі мен ең аз жалпы бастапқы құны есептеледі. Клиент дайындық тізімін жүргізіп, жобасын осы браузерде сақтай алады және жоспарды файлға шығарады. Бұл мүмкіндіктер дерекке негізделген негізгі іріктеуді клиенттің жоспарлау жолымен байланыстырады.

Ұқсас сервистерді зерттеу мен өзіміз іске асырған шешімдердің байланысы: [RESEARCH.md](RESEARCH.md).

### Платформадағы әрекеттер

1. Өзгерістер біріктірілгеннен кейін негізгі демоны жергілікті іске қосып тексеріңіз; тест командасы README-де берілген.
2. Соңғы код пен README-ді **платформа берген команда репозиторийіне** жіберіңіз: `BAITC-Hacks/hack-96ac4fd9-7-s-ai`.
3. Репозиторийге қатынауды команда мүшелері және ұйымдастырушылармен шектеңіз. Киберқауіпсіздік нұсқаулығы осыны талап етеді; оны жалпыға ашық ету талап етілмейді.
4. Хакатон платформасында тректі және **«Мердігерлерді ақылды іріктеу»** кейсін ашыңыз.
5. **«Шешімді тапсыру»** батырмасын басып, **Firebird** атауын және жоғарыдағы сипаттаманы енгізіңіз.
6. Платформадағы қабылданған шешімді тексеріңіз. Нұсқаулық бойынша шешімді дедлайнға дейін жаңартуға болады.

Нақты дедлайн сағаты берілген PDF нұсқаулықтарда көрсетілмеген: платформаның ағымдағы таймері мен ұйымдастырушылар хабарламасын қолданыңыз. README-де орналастырылған нұсқаға сілтеме бар болса беріледі; жалпы нұсқаулықта орналастыру немесе өз демо бейнеңізді жүктеу міндеті жазылмаған. Берілген YouTube сілтемесі — тапсыру жөніндегі бейне нұсқаулық.
